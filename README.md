# Restoping

Restoping is a food ordering platform/website. It consists of a Backend API and a Frontend application (Web & Mobile).

## Project Structure

- **[Backend](./Backend)**: Node.js/Express API server.
- **[Frontend](./Frontend)**: React application with Vite, Firebase, and Capacitor for mobile support.
